# Eventer — Brandbook (Руководство по стилю)

Данный брендбук описывает визуальный язык платформы (цвета, шрифты и компоненты), настроенный для максимальной чистоты, читаемости и современного внешнего вида (Clean UI / Shadcn).

---

## 🎨 1. Цветовая палитра (Colors)

В основе лежит монохромная база с мощным и доверительным зеленым акцентом.

### Акцентные цвета (Action Colors)
- **Primary Green (Основной акцент)**: `#16A34A` (Tailwind: `bg-green-600`)
  - **Применение**: Главные кнопки (сохранить, подробнее, применить), иконки (календарь, локация, пользователи), чекбоксы.
  - **Hover (Наведение)**: `#15803D` (Tailwind: `bg-green-700`) — более глубокий зеленый.
- **Success / Badge (Фон для лейблов)**: `#DCFCE7` (Tailwind: `bg-green-100`) 
  - **Применение**: Подложки под иконки, фон активных бейджей. В темной теме используется полупрозрачный: `rgba(22, 163, 74, 0.2)` (`dark:bg-green-500/20`).

### Базовые цвета (Поверхности / Surfaces)
Соблюдаются строгие токены Shadcn для идеальной поддержки Light / Dark Mode.
- **Background (Фон страницы сайта)**: Светлая тема: `#FAFAFA` (zinc-50) | Темная: `#09090B` (zinc-950)
- **Card (Карточки)**: Светлая: `#FFFFFF` | Темная: `#09090B` (zinc-950)
- **Border (Границы)**: Светлая: `#E4E4E7` (zinc-200) | Темная: `#27272A` (zinc-800)

### Типографика (цвета текста)
- **Primary Text (Заголовки и важный текст)**: `#09090B` (zinc-950) / `#FAFAFA` (zinc-50)
- **Muted Text (Второстепенная информация, даты)**: `#71717A` (zinc-500) / `#A1A1AA` (zinc-400)

---

## ✒️ 2. Типографика (Typography)

Для платформы мероприятий требуется максимальная читаемость. Мы используем гротески (sans-serif) без засечек.

### Основной шрифт: Inter (Google Fonts)
Входит в состав стандартного стека Shadcn. Обеспечивает строгий и супер-читаемый UI.
* **Alternate (Опционально для заголовков)**: **Outfit** или **Geist** — если хочется дать платформе более "технологичный" вид.

### Иерархия размеров (Text Sizes & Weights)
- **H1 (Главный заголовок страницы)**: `text-3xl` (30px), Вес: `font-bold`, Межбуквенный интервал: `tracking-tight` (-0.025em). Придает заголовку "Все мероприятия" строгости.
- **H3 (Заголовки карточек мероприятий)**: `text-2xl` (24px) / `md:text-[26px]`, Вес: `font-bold`, Интервал: `leading-tight` (плотный межстрочный).
- **H4 (Подзаголовки, "Описание")**: `text-lg` (18px), Вес: `font-semibold`.
- **Primary Body (Описание мероприятий)**: `text-base` (16px), Вес: `font-normal`, Интервал: `leading-relaxed` (1.625). Длинные тексты должны "дышать" и отлично читаться.
- **Meta (Место, Время, Даты)**: `text-[15px] md:text-base` (15px - 16px), Вес: `font-medium`. 
- **Button Text (Текст в кнопках)**: `text-[14px]`, идеальный баланс между читаемостью и компактностью.

## 🧩 3. Компоненты и стили (UI Elements)

### Карточки (Cards)
- **Shadows (Тени)**: Используются только чистые, очень мягкие тени `shadow-sm` (`0 1px 2px 0 rgba(0, 0, 0, 0.05)`).
- **Hover-эффекты (Наведение)**: При наведени мы избегаем изменения цвета фона. Карточка просто получает тень `hover:shadow-md`, создавая естественный 3D-эффект отклика.

### Изображения (Images)
- При наведении на карточку картинка плавно увеличивается: `transition-transform duration-500 group-hover:scale-105` (Эффект "Ken Burns").

### Кнопки (Buttons)
- **Главные действия**: Зеленая заливка (`bg-green-600`), скругленные углы, внутри текст `text-[14px]`. Текст строго белого цвета.

### Бейджи (Badges)
- Отказались от резких и глухих фонов (типа `bg-gray-600`).
- **Стиль**: Нежный фоновый полутон (`bg-[color]-100`) + Читаемый цвет текста (`text-[color]-700`) + Тонкая гравирока (`border-[color]-200`). Этот паттерн называется **"Soft Badge"** и выглядит современно.
  - Активный: Светло-зеленый
  - Предстоящий: Светло-синий
  - Завершен: Светло-серый
  - Онлайн/Офлайн: Контурные бэйджи (Outline) с очень легкой заливкой.
